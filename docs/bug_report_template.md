## Example (SauceDemo `problem_user`)

| Field | Details |
|-------|---------|
| Bug ID | BUG-001 |
| Title | All products show the same dog image when logged in as `problem_user` |
| Module | Inventory |
| Environment | Chrome, Windows 11, https://www.saucedemo.com |
| Severity | Minor |
| Priority | Medium |

**Steps to reproduce**
1. Open https://www.saucedemo.com
2. Login with `problem_user` / `secret_sauce`
3. Look at the product images on the Products page

**Expected result**: each product shows its own image.

**Actual result**: every product shows the same dog image.
